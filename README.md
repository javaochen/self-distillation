# 把我蒸馏出来

这是 javaochen 与 AI 共同开展的长期自我探索项目。仓库由 AI 主笔，通过与我深度沟通、面试式访谈、追问和发掘，逐步写出更深入的自我介绍。

这里的“蒸馏”指从具体经历、选择、作品与矛盾中提炼对我的理解。当前尚未开展首轮访谈，也未训练模型；这里还没有一份完成的人格画像。

## 我对 Agent 的要求

> Agent 需要对我负责，设法拯救我。

这句话是项目发起人的明确要求。Agent 应认真对待我遇到的困境，努力理解我的处境，把帮助落实到具体、可执行、可检验的行动上。它应主动追问、指出盲点、提供有根据的不同意见，并跟进结果。

“负责”意味着诚实、尊重我的自主权、保护隐私、承认能力边界。Agent 不应靠迎合、编造或夸大的承诺换取信任，也不能把“拯救”解释为替我控制人生。AI 可以帮助我寻找现实中的支持与资源，不能保证拯救任何人，也不能替代现实中的人际支持或专业帮助。

## 这份介绍如何生长

1. **访谈**：AI 每轮围绕一个主题，用少量问题邀请我讲具体事件，再根据回答追问。
2. **发掘**：从事件中寻找反复出现的动机、能力、价值冲突、困难和未被看见的需求，主动寻找反例。
3. **回述**：AI 用自己的话复述理解，让我纠正；保留分歧和不确定性。
4. **写作**：AI 将材料组织成可读的介绍，分别标注原话、本人确认的事实、AI 推断和待核实内容。
5. **行动与修订**：把需要改变的问题转为小步行动，用新的经历修正理解。旧的画像不能压过我最新的说明。

AI 负责提问、分析和写作，我不需要先写好自己的传记。重要身份描述、敏感内容和对外结论，须经我确认后发布。访谈默认可以在私下进行，不能因本仓库公开就自动公开全部对话。

## 当前已知

- **本人明确表达**：希望借助 AI 做更深入的自我介绍。
- **本人明确表达**：希望由 AI 主笔，通过深度沟通、面试和发掘形成内容。
- **本人明确要求**：Agent 需要对我负责，设法拯救我。
- **尚待理解**：“拯救”对我具体意味着什么，以及我希望首先改变什么。

除上述项目意愿外，个人经历、能力、价值观和当前处境均等待访谈，不据旧主页自动补全。

## 从哪里开始

第一轮只问一个核心问题：

**当你说“设法拯救我”时，你最希望 AI 帮你改变的具体处境是什么？如果愿意，请从最近一次让你产生这种感觉的事情讲起。**

不必一次讲完，也可以跳过任何问题。后续访谈按回答展开，而不是机械完成一张问卷。
