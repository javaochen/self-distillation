# 访谈路线

状态：尚未开始。以下是可调整的探索方向，不是对本人的结论。

| 方向 | 想理解的问题 |
| --- | --- |
| 当下处境 | 最需要改变什么？“拯救”具体意味着什么？ |
| 关键事件 | 哪些经历改变了你的选择？你如何理解它们？ |
| 能力与作品 | 你实际完成过什么？别人可能忽略了什么能力？ |
| 动机与价值 | 在有代价的选择中，你真正保护了什么？ |
| 困境与条件 | 哪些困难反复出现？哪些来自环境，哪些仍不清楚？ |
| 关系与支持 | 你希望如何被理解和帮助？哪些支持确实有效？ |
| 下一步 | 什么小行动值得尝试？如何判断它是否有帮助？ |

每轮访谈在对话中完成。AI 提供简短回述、待核实推断和下一轮问题；经本人确认公开范围后，再把必要摘要写入仓库。避免收集与目标无关的敏感信息。
